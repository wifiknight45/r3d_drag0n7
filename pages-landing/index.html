Professional-grade natal compute (Swiss Ephemeris / Skyfield / offline) with a Dragon Studio web UI. This GitHub Pages site is the landing — full interactive casting needs the local API.

Docs on GitHub How to run

Pages hosts the brand landing only. Clone the repo and start uvicorn web.app:app for live charts + AI hooks.

Dragon Studio

Dark-sky UI with Chinese dragon motifs. Form → loading coil → placements, summary, SVG wheel.

Three modes

Nostradamus (Swiss), Ptolemy (Skyfield), Paranoid (offline). House systems: Placidus, Equal, Whole, Porphyry, Campanus.

AI hooks

Optional natal enrichment via OPENAI_API_KEY / PERPLEXITY_API_KEY, or local heuristic rewrite.

CLI + library

Keep using sistema_enhanced.py from the terminal; the web layer imports it carefully without rewriting the engine.

Computation modes

  • Nostradamus — high-accuracy Swiss Ephemeris
  • Ptolemy — Skyfield fallback
  • Paranoid — offline-leaning operation

Run Dragon Studio

git clone https://github.com/wifiknight45/r3d_drag0n7.git
cd r3d_drag0n7
pip install -r requirements-web.txt
# optional: pip install skyfield pyswisseph geopy timezonefinder requests
uvicorn web.app:app --reload --port 7860

Then open http://127.0.0.1:7860 — see web/README.md and docs/AI_ENHANCEMENTS.md.
